# Overview

Visto is a mobile testing tool driven by a multimodal AI. The user describes
a test goal and expected result; the AI navigates the app from screenshots and
judges observed results in one conversational loop. Appium/ADB execute technical
operations only. Android and iOS are implemented; iOS has had local checks only.

Entry points: the web console (see [web console](../web-console.md)) and the
headless CLI (see [first device test](../first-device-test.md)), both running
locally (see [installation](../local-development.md)).

See [product intent](../product/vision.md) and [STATUS](STATUS.md).
